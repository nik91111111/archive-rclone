Personal Archive Utility

This is a private archiving utility used by its operator for their own Google Drive account. It uses rclone on the operator’s Mac to upload selected modelling project files, check file sizes and checksums, and retrieve archived files when needed. It is not a customer-facing sign-in service.

Privacy and Google Drive data

The utility requests Google Drive access to read file contents and metadata, create and organise archive folders, upload files, and verify archived copies. The Google permission includes the ability to modify and delete Drive files; operations are limited by the operator’s chosen commands and archive workflow.

Selected project files are transferred between the operator’s Mac and Google Drive. File names, paths, sizes, checksums and transfer results may be stored in local archive manifests and logs. OAuth credentials are stored in the operator’s local rclone configuration, rather than on this public website.

The archiving utility does not sell Google user data or use it for advertising. It does not publish archived files on this website. Google Drive stores the cloud copies under the account’s existing sharing settings.

The operator controls archive retention and deletion. Revoking this utility’s access in the Google Account’s third-party connections settings stops future authorised access; it does not itself delete files already stored in Drive or local manifests and logs.

This notice describes the archiving utility. This public page is hosted by GitHub Pages; GitHub may process visitor information under its own privacy statement. This page contains no archive files or OAuth credentials.

For questions about this private utility, contact the account operator using the support contact shown on the Google consent screen.
